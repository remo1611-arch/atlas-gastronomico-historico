# Política cartográfica gastronómica

## Mapa base

Mapa mundial moderno desaturado, únicamente para orientación.

## Capas futuras

El Atlas podrá mostrar:

- ocurrencias puntuales;
- áreas arqueológicas;
- regiones productoras;
- rutas comerciales;
- difusión documentada;
- áreas de cultivo;
- indicaciones geográficas históricas;
- itinerarios de textos/recetas.

## Reglas

- no rellenar países modernos para representar culturas alimentarias antiguas;
- no dibujar una “ruta de difusión” si solo existen dos puntos aislados;
- no confundir lugar de primera evidencia con origen biológico;
- las rutas requieren fuente;
- las áreas requieren geometría o reconstrucción identificable;
- la incertidumbre espacial debe ser visible;
- una macroregión no se representará como un punto preciso salvo que se marque como referencia visual.
